# 学到口口相传的硬气功就能横行江湖了呀

## Current conclusion

**答案 = 开会（已判正确）。**

官方提示：本 meta 使用的漫画素材 id = **5、12、38、43**，正好是四个 2 字黑块。

```
成语1  [触目]皆是        ← 038 触目      常见、满眼都是
  ↕ 反义
成语2  [铁树][开]花      ← 043 铁树      极罕见／极难      **红 = 开**
  ↕ 反义
成语3  易如[反掌]        ← 012 反掌      极容易
  ↕ 同义
成语4  [会]者[不难]      ← 005 不难      会的人不觉得难    **绿 = 会**
  ↕ 重排 + 反义
成语5  难者不会（全灰）                  难的人不会
```

语义分组 1≈3≈4（常见／容易）、2≈5（罕见／难），与图上箭头完全一致；
四个黑块的形状（前二／前二+第3字红／后二／首字绿+后二）也逐一吻合。

**此前六次失败（远大·中外·熟知·自我·相貌·可以）的三个原因：**
1. 一直假定「铁树开花」的反义在**难易**轴上（唾手可得那一族），实际在**常见/罕见**轴上 —— **触目皆是**；
   而 038「触目」我从头到尾只想到「触目惊心」。
2.「重排+反义」只在**四字成语词典**里找，而正解是俗语 **「会者不难，难者不会」**（同四字完全倒序、意思相反），字典里查不到。
3. 005「不难」找不到能以它收尾的**成语**，因为它收尾的是**俗语**。

### 旧版推理（保留备查）

> **可以 已于 2026-08-20 判错。**


**答案 = 可以。**

突破口是最强约束「成语4 ↕**重排+反义** 成语5」。把三万条成语库里所有**同字异序**的成语对全部枚举，
再筛出真正互为反义、且落在「难/易」轴上的，只剩一对：

> **以卵投石 ↔ 以石投卵**
> （前者「拿蛋碰石头，自取灭亡」；后者「用石头砸鸡蛋，以强攻弱必胜」）

两条首字都是「以」⇒ **绿 = 以**，且成语4 的形状 `[绿=以][灰=卵][黑黑=投石]` 完全吻合。

由此反推：**铁树开花只能是成语1**（`[黑黑][灰][灰]` 同样放得下 铁树|开|花），不是成语2——
若是成语2 则红=开，而「开+以」不成词。

语义链闭合（1≈3≈4 难/办不到，2≈5 易）：

| 行 | 成语 | 说明 |
| --- | --- | --- |
| 1 | **铁树**开花 | feeder **043**；极难实现 |
| 2 | ■■ + **可**(红) + ■ | 唾手**可**得／指日**可**待／垂手**可**得 —— 这类反义成语第 3 字一律是「可」|
| 3 | ■■ + **投石**? | 自不量力必败（以卵击石／螳臂当车／蚍蜉撼树）|
| 4 | **以**(绿)｜卵｜**投石** | |
| 5 | 以石投卵（全灰，由重排+反义自推）| |

**答案 = 可 + 以 = 可以。**

### 旧版推理（保留备查）



**答案 = 可以**（红 = 可，绿 = 以）。

### 1. 先钉死「重排 + 反义」这条最强约束（成语4 ↔ 成语5）

拿 3 万条成语库（chinese-xinhua idiom.json）穷举「同字异序」的成语对，
再筛「两条互为反义」，落在**难 / 易**这条语义轴上的，只有一对活下来：

| | 成语 | 释义 |
| --- | --- | --- |
| 成语4 | **以卵投石** | 拿蛋去碰石头。比喻不估计自己的力量，自取灭亡（＝办不到） |
| 成语5 | **以石投卵** | 用石头去砸鸡蛋。比喻以强攻弱，**必胜无疑**（＝轻而易举） |

同字重排 ✓、语义相反 ✓、成语4 形状 `[绿=以][灰=卵][黑黑=投石]` ✓。
**两条的首字都是「以」⇒ 绿 = 以**（即使 4/5 互换，绿仍是「以」，非常稳）。

对照排除：事半功倍/事倍功半（绿=事）、举重若轻/举轻若重（库中无后者）、
知易行难/行易知难（已排除）、化整为零/化零为整（语义不在难易轴）——
它们的首字都无法与任何合理的红字组成常用词。

### 2. 铁树开花 是**成语1**，不是成语2

`[黑黑][灰][灰]` 与 `[黑黑][红][灰]` 都能放下「铁树｜开｜花」。
若放成语2 则红＝开，答案＝「开+绿」；但穷举后 `开X` 与任何「重排+反义」对子的
首字都不成词（开以 ✗、开事 ✗、开举 ✗…），且成语4 必须「同义于易如反掌」而
库中没有这样的重排对。故 **铁树开花 = 成语1**（feeder 043 = 铁树）。

### 3. 语义链闭合

```
成语1  铁树[043] 开 花        极难实现 / 罕见
   ↕ 反义
成语2  [黑黑] 可(红) [灰]      唾手可得 / 指日可待 / 触手可及 / 垂手可得 —— 极易、为期不远
   ↕ 反义
成语3  [灰][灰][黑黑]          自不量力、必然失败（如 以卵击石 / 螳臂当车 / 蚍蜉撼树）
   ↕ 同义
成语4  以(绿) 卵 [投石]        以卵投石
   ↕ 重排 + 反义
成语5  以 石 投 卵            以石投卵 —— 以强攻弱、必胜无疑
```

1≈3≈4（难/办不到）、2≈5（易）完全自洽。

### 4. 红 = 可

成语2 形状 `[黑黑][红][灰]`，语义须是「铁树开花」的反义（极容易 / 不久就能实现）。
库中该类成语几乎清一色是 `??可?`：唾手可得、唾手可取、垂手可得、反手可得、
触手可及、指日可待、计日可待、指掌可取、企踵可待 …… ⇒ **红 = 可**。
而红 + 绿 = 红 +「以」要成词，候选 可以 / 所以 / 何以 / 足以 / 难以 中，
只有 **可以** 能由「??可?」型成语给出，其余的第 3 字都凑不出「极易」类成语。

**答案 = 可 + 以 = 可以。**

### 5. 本图占用的 feeder

铁树(043) + 成语2 前二字（唾手 / 指日 / 触手 / 垂手 之一）+ 成语3 后二字
（击石 / 当车 / 撼树 / 量力 之一）+ **投石**（成语4 后二字）。
后三个应落在尚未破解的 007/013/020/028/031/032/041/055/060/066/067/070 里。
注意：012 反掌、038 触目 在本图**用不上**（它们只能配「易如反掌」「触目皆是」，
而那两条在正确的语义链里没有位置），应归到别的 meta。

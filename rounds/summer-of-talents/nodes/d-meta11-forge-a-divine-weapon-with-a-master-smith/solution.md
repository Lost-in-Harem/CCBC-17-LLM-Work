# 在天下最有名的工匠帮助下打造神兵利器

## Current conclusion

**答案 = 立业（已判正确）。**

官方提示：本 meta 使用的漫画素材 id = **8、11、45、53、58**。
五道小题（第/冠/首 各 1 字，习习/春秋 各 2 字，共 7 字）要填 6 个黑块，只有唯一分法：

```
[第]011 { 一 = [冠]058 = [首]045
          二 = [习习]053 → 羽（写在半高块里）+ [立]红 = **翌**（翌日＝次日）
                =  [一] + [业]绿 = **亚**（亚军＝第二）
          三 = [春][夏][秋][冬]  ← 008「春秋」落在第 1、3 位，夏/冬 为灰（可自推）
        }
答案 = [红] + [绿] = 立 + 业 = **立业**
```

三条印证：① 行2 上半是**半高**块，正好装「习习」并排写成的**羽**；
② 行3 的黑1 与黑3 在像素上是**同一条黑长条**被中间灰块盖住，即一个双字答案被拆到第 1、3 位；
③ 统辖字只能是「第」——只有它能同时统辖 第一/第二/第三。

### 旧版推理（保留备查）

> **立业 已于 2026-08-20 判错。**


**答案 = 立业。**

序数体系：`[第] { 一 = 冠(058) = 首(045)；二 = [黑上/红下] = [一+绿]；三 = 四字词 }`

**行 2 项 1 = 翌**（**翌日 = 次日 = 第二天**，表「第二」）：

- **翌 = ⿱羽立**
- 上半黑块 = **羽**，而 `羽 = ⿰习习` ⇒ 正是已确认却一直未归位的 feeder **053「习习」**
  （作为合成字的上部件只占半格，与 d-meta07 把「置」画成 四(上)+直(下) 同一惯例）
- 下半红块 = **立**

行 2 项 2 = **亚** = ⿱一业（亚军 = 第二）⇒ **绿 = 业**。

**答案 = 红 + 绿 = 立 + 业 = 立业**（成家立业／建功立业）。

穷举依据：用 cjkvi-ids 全量 IDS + Unihan 释义扫描所有「⿱ 上下结构且释义含 second/next/次/明日」的汉字，
只有 **亚(⿱一业)** 与 **翌(⿱羽立)** 两个；贰/弍/仲/副/次/两/双/乙 均不符合「上下结构 + 下半自成一字」。
而「下半 X 能与业成词」的全族（空→工业、天→大业、歪→正业、笨→本业、森→林业、众→从业、并→开业…）里，
语义上真正表「第二」的只有 **翌 → 立业**——**官方已判错的 工业/大业/正业 恰好是这族里语义不合格的三个**。

### 旧版推理（保留备查）



**结构改判（2026-08-19，重看原图）**：左边三行的「横」右端**带箭头**，
且行 2 右侧绿块的**正上方单独压着一条同样的横**——横不是宋体衬线，而是**被添加的笔画**。

```
[黑 X] { ─→        = [黑1字] = [黑1字]          （X 加一横，两个结果）
         ─→ ─→     = [黑上/红下] = [─ + 绿]      （X 加两横，两个结果；第二个把横画在绿字头上）
         ─→─→─→    = [黑][灰][黑][灰]           （X 加三横，四个结果）
       }
答案 = [红] + [绿]
```

这一读法同时解释了三件原本说不通的事：

1. 行 3 为什么是**四个各自独立的单字格**（＝四个结果，不是一个四字词）；
2. 绿块头上为什么多出一条横（＝那条被加上去的笔画，故该结果 = 一 + 绿）；
3. 为什么全图黑块**清一色 1 字宽**——所有结果都是单字，本图正是全区「单字答案」的集中地。

**像素实测修正（重要）**：行 3 的四个格**互相紧贴**（x 503→505、584→585、665→665），
且每格只有 **80×80**，比行 1／行 2 的 **99×99 小一号**；四格总跨度 425–745，
恰好等于行 1／行 2「两个项 + 等号」的整段宽度。
⇒ **行 3 右边是一个四字词**（字号压小以塞进同宽），而不是两个 2 字项；
行 1／行 2 则是**各两个单字项**，中间以「=」分隔。

行 3 的「黑灰黑灰」交替很像 **说三道四 / 张三李四 / 颠三倒四 / 丢三落四 / 接二连三**
这一类词——第 1、3 字是小题答案（黑），第 2、4 字正是那两个数字（灰，可自行推出）。

推论：**绿 = X 加一横之后的某个字**（因为「X 加两横」= 「X 加一横」再加一横，
而第二个结果被画成「一 + 绿」）。红 = 行 2 第一个结果的下半。

### 2026-08-19 新增：绿 = 业

行 2 项 2 的那条横**宽 89px，而其下绿块宽 98px** —— 首横比主体**窄**。
这排除了「一」处于全字最宽位置的所有候选（百、丙、再、末、灭、下、万、两），
只剩 **亚(一+业)、王(一+土)、天(一+大)、未(一+木)、正(一+止)、三(一+二)**。

该行左侧是「二」，而上述候选里**只有「亚」本身就表示第二**（亚军 = 第二名）。
⇒ 行 2 项 2 = **亚**，**绿 = 业**，**答案形如「■业」**。

红 = 行 2 项 1（一个上下结构单字）的**下半**，且须与「业」成词。
能充当「上下结构字下半」的候选：工(空)、大(尖/类/奖)、正(歪)、本(笨)、木(李/杏/果)、各(客)、分(盆/芬/岔)
→ ~~工业~~ ~~大业~~ ~~正业~~ **全部判错** ⇒ 「绿=业」这条推导（依赖「行2 代表二、只有亚＝第二」这一语义假设）很可能不成立，已降级。
剩余可能的绿：土(王)、大(天)、木(未)、止(正)、二(三)。

另一条尚未与之调和的线索：行 3 四字词的第 1、3 字是两道**单字**小题的答案，
而未归位的单字答案恰有 062「远」与 027「控」——「**远**程**控**制」正好第 1、3 位。
两条线索指向不同体系，必有一错。

### 2026-08-19 再更新：045 = 首 落位，行 1 闭合

官方确认 feeder **045 = 首**（单字）。「首」＝第一，与 **058 冠**（冠军＝第一）正好是
行 1 那两个 1 字黑块 ⇒ **统辖字 = 011「第」**（第一／第二／第三），本图读法确定为**序数体系**：

```
[第] { 一 = 冠(058) = 首(045)
       二 = [黑上 / 红下] = [一 + 绿]   ← 后者 = 亚（一+业），故 绿 = 业
       三 = [黑][灰][黑][灰]（一个四字说法）
     }
答案 = [红] + [业]
```

全区仅剩的两个未归位单字答案（冠、首）在此一次性落位，
这同时把「绿 = 业」重新扶正（候选 亚/王/天/未/正/三 中只有「亚」本身＝第二）。

仍缺：红 = 行 2 第一项那个**上下结构、且表示「第二」的单字**的下半。
已排除 工业、大业、正业。已确认且未归位的单字答案只剩 011「第」、058「冠」，应是其中两个结果。

### 提取式的结构约束（可直接用于反查）

- **红 = 行2 项1 的下半**：该字必须是**上下结构**、且下半自成一字（如 第=竹/弟、思=田/心、
  泉=白/水、员=口/贝、您=你/心、安=宀/女、男=田/力）。
- **绿 = 行2 项2 去掉首笔横**：该字必须是「一 + 某个完整汉字」。穷举常用字后候选很有限：
  **天=一+大、百=一+白、王=一+土、丙=一+内、干=一+十、灭=一+火、再=一+冉、
  末/未=一+木、下=一+卜、三=一+二、兀=一+儿**（页=一+丿+贝、石=一+丿+口 需多一撇，较弱）。
  ⇒ **绿 ∈ {大, 白, 土, 内, 十, 火, 冉, 木, 卜, 二, 儿}**，答案第二个字几乎一定在这里面。

## Working hypotheses

统辖字最可能是 **011「第」**（唯一能统辖 一/二/三 的已确认单字答案：第一/第二/第三）。
但没有任何一个「第一/第二/第三」体系能同时满足「行1、行2 各是两个**单字**、行3 是**四个字**」：

| 体系 | 一 | 二 | 三 | 判定 |
| --- | --- | --- | --- | --- |
| 名次 | 冠 | 亚 | 季 | 行3 只有 1-2 字 ✗ |
| 天干/地支/生肖 | 甲/子/鼠 | 乙/丑/牛 | 丙/寅/虎 | 行3 ✗ |
| 五声/工尺 | 宫/上 | 商/尺 | 角/工 | 行3 ✗ |
| 先天八卦 | 乾/天 | 兑/泽 | 离/火 | 行3 ✗ |
| 三教 | 儒/孔 | 释/佛 | 道/老 | 行3 ✗ |
| 人称代词 | 我/吾 | 你/汝 | **他她它牠（4 字！）** | 行3 ✓，但行2 的「你/汝/您/尔」凑不出「一+整字」的结构 ✗ |
| 化学甲乙丙（酸） | 甲/蚁 | 乙/醋 | 丙/？ | 行2 的 乙、醋 不是上下结构 ✗ |

**唯一同时解释「2 项 / 2 项 / 4 项」的方向**是：行3 其实是**四个并列的单字项**（因宽度不够
省掉了等号），例如「一有两种异写、二有两种、三有四种」。数字大写异体（壹/弌、贰/弍、
叁/弎/參/叄）计数恰为 2/2/4，但 贰/弍 的字形对不上「顶横 + 整字」。

其他仍在候选的读法：
- 左字是**多音字**，一/二/三 是《汉典》式按读音编号的义项，行3 是该读音的四字例词；
- 「=」表示**同音**，一/二/三 是声调（行1 一声、行2 二声、行3 三声）——若如此，
  行2 项2 只能是 **王（wáng）= 一 + 土**（绿 = 土）这一类，但行2 项1 找不到合适的上下结构同音字。

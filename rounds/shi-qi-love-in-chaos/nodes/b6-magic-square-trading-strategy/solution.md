# 幻方的交易策略

## Current status

**当前无答案候选；`阳数` 已被用户明确判错。**

57/57 的拆解频次数盘仍是已确认的主机制，但五音配五方属于题外文化映射，判题已证明它不是终落点。四笔高频交易的 `古筝／西北` 读法也不再视为可靠：每笔方向没有题面箭头，后续四个不同落点均告失败。当前只保留题内完全机械的两条事实：`关键词` 是唯一重复三字块；它的两次交易对象依次为 `古代人／的概念`。

## 1. 三字块在交叉点交易

- 去掉标点，并把每处四条下划线视作两个汉字空位后，50 行线索恰好拆成 180 个连续三字块。
- 每个横、纵分组的块数多重集与对应白格线长多重集完全一致。
- 将 G1、G2、G3 居中放进同一 13×13 坐标系，恰有 5 个坐标在三盘中同时开放；它们是普通 crossword 没有的深度（`里`）方向。
- 在 42 个平面横纵交叉和 15 个里向交叉处交换相交线索的三字块，57 次全部反向交换后可同时恢复 50 条自然线索。

代表性复原包括：

| 复原线索 | 答案 |
| --- | --- |
| 雷锋是每个小朋友的好□□ | 榜样 |
| 地质学领域中经常被叫作父 | 莱尔 |
| 发生后伤害数字变大 | 易伤 |
| 如《童年》《悲惨世界》《巴黎圣母院》 | 名著 |
| 记忆中厕所里的味道 | 氨气 |

三处空白分别补为 `榜样 / 曼丽 / 气性`；它们用于完成线索，不是终答案。

## 2. 拆解答案，以方向内频次填格

提示 2 和风味文本中的“拆解”要求把答案拆成有序可见部件，直到部件数等于格长。例如：

| 答案 | 拆解 | 方向内频次数列 |
| --- | --- | --- |
| 榜样 | 木 / 旁 / 木 / 羊 | 2121 |
| 莱尔 | 艹 / 来 / ⺈ / 小 | 2112 |
| 易伤 | 日 / 勿 / 伤 | 111 |
| 名著 | 夕 / 口 / 艹 / 者 | 1121 |
| 氨气 | 气 / 安 / 气 | 212 |

关键点是频次要分别在题面的三个方向 `横 / 纵 / 里` 内统计，而不是混合统计全部答案：

| 方向 | 频次为 2 的部件 |
| --- | --- |
| 横 | 凵、月、队、木、又、气 |
| 纵 | 艹、小、㇏、又、田 |
| 里 | 气 |

其余部件频次均为 1。把各部件在本方向的频次填进格子后，全部 **57/57** 个交叉点两边数字相等。这个约束也消除了若干语义近似答案：必须使用 `莱尔` 而非泛称地质学家、`易伤` 而非暴击、`名著` 而非世界名著、`氨气` 而非尿骚味。

## 3. 五条里向线索与中间词 BREAK

五个三盘共同坐标形成五条深度线：

| 坐标 | 复原的里向线索 | 答案 | 数列 |
| --- | --- | --- | --- |
| r04c04 | 一个可有可无的影子 | 路人甲 | 111 |
| r04c10 | 学狐狸能达成这件事 | 成精 | 111 |
| r07c07 | **结束本部分的关键词** | **BREAK** | 111 |
| r10c04 | 两根骨头连接根与尖 | 关节 | 111 |
| r10c10 | 记忆中厕所里的味道 | 氨气 | 212 |

`r07c07` 是三张居中盘面的共同正中心。该线直接询问“结束本部分的关键词”；结合算法工程师风味，它可自然解成编程关键字：

**BREAK**

用户已明确判定 `BREAK` 不是最终答案。因此提示 3 确实建立了第三维，但不能把“共同正中心”额外假定为终点；`BREAK` 应按其程序语义结束当前部分，并把解题流程交给下一段机械提取。把它暂分为 `B / RE / AK` 只与该线的 `111` 数值相容，不构成唯一拆法或终答案证据。

## 4. 高频交易提取：古筝／西北

在自然可见部件拆法中，恰有四个实际交易点的交叉频次为 2。六个独立的 57/57 搜索都保留这四点；非交叉处的若干等价拆法不会改变它们。每个被交易的线索块恰有三个汉字，因此数值 2 机械地选取双方三字块的中间字；复原答案 `反切` 指示把每对字作声韵拼合：

| 顺序 | 居中坐标 | 复原后的交易块 | 第 2 字 | 反切读音 |
| ---: | --- | --- | --- | --- |
| 1 | G1 r06c12 | 在干活 / 吃兔子 | 干 / 兔 | `g + u = GU` |
| 2 | G1 r08c02 | 地质学 / 雷锋是 | 质 / 锋 | `zh + eng = ZHENG` |
| 3 | G1↔里 r10c10 | 气性不 / 记忆中 | 性 / 忆 | `x + i = XI` |
| 4 | G3↔里 r10c10 | 六百号 / 的味道 | 百 / 味 | `b + ei = BEI` |

每组交换可以有两个反切朝向。去掉普通话不成立的组合后共有八种有限组合，其中唯一能连续分词的自然短语是：

```text
GU / ZHENG / XI / BEI  ->  古筝 / 西北
```

正中心里线的答案 `BREAK` 正好把四音节切成“领域／方位”两半，而不是终答案。

## 5. 关键词交易与五音配五方

复原后的 180 个三字块中，唯一重复的是 `关键词×2`。两块各自交易出去的对手，按复原行顺序为：

```text
古代人 / 的概念  ->  古代人的概念
```

这给出终落点的定义。`古筝` 则把要用的古代体系限定为五音；在五音配五方的对应中：

| 方位 | 东 | 南 | 中 | 西 | 北 |
| --- | --- | --- | --- | --- | --- |
| 五音 | 角 | 徵 | 宫 | 商 | 羽 |

所以 `西北` 固定对应 `商羽`，不再需要任意选择八卦、地图朝向或五条里线。像题中的交易对一样从两个方向作反切：

| 字对方向 | 反切 | 音节 |
| --- | --- | --- |
| 商羽 | 商的声母 `sh-` + 羽的韵母 `-u` | `SHU` |
| 羽商 | 羽的声母 `y-` + 商的韵母 `-ang` | `YANG` |

本地两字词典对 `SHU/YANG` 两种次序的有限穷举只有六个落点：`杨树、输氧、沭阳、样书、阳数、杨淑`。其中只有 **阳数** 符合另一条机械定义“古代人的概念”；在传统阴阳数观中，奇数即阳数。定义同时消除了同音字和顺序歧义：

```text
YANG / SHU  ->  阳数
```

用户已经明确判错 **阳数**。因此“五音配五方→商羽→正反反切”的整段解释移入失败路线，不再承担终提取。

## Rejected candidate audit

- **交易闭合：** 180 个三字块、50 条线索、57 个交叉全部由同一“交叉处交换”规则解释。
- **拆解闭合：** 部件数逐条匹配格长，回应提示 2；方向内频次数盘在 57 个交叉全部一致。
- **三维闭合：** 五个共同坐标恰好承载五条 `里` 线，回应提示 3。
- **高频闭合：** 方向内频次恰好选出四笔值 2 的交易；值 2 同时索引三字交易块，题内答案 `反切` 读出 `古筝／西北`。
- **BREAK 闭合：** 正中心词把四音节分成乐器领域与两个方位，不再被误当终答案。
- **古代体系闭合：** `关键词×2` 的交易对象直接给定义“古代人的概念”；古筝和西北共同限定五音配五方，给出 `商羽`，无需分别套两个不相干的转换体系。
- **落点闭合：** `商羽／羽商` 正反反切为 `SHU/YANG`；本地有限同音落点中仅 `阳数` 符合定义。
- **剩余风险：** 第一层四个交易对仍靠“唯一连续自然短语”消歧局部朝向，而不是题面逐笔画箭头；但后续五音映射同时精确使用 `古筝、西北、古代人的概念、交易、反切`，显著强于已判错的单独转义。
- **判题结论：** 用户已明确判错 `阳数`；以上文化映射不能恢复。

# 幻方的交易策略

## Current status

**状态：`candidate`；当前候选 `CORPORATE STRUCTURE`，置信度 `medium`。**

用户已明确判错 `CONCUBINE`，所以 `企业的反切 -> qiè -> 妾` 已整体撤销。
新的区别不是改换 `CORPORATE` 近义词，而是把此前闲置的第二段严格音流
`GU/GE` 接回主链：两笔最高频 `关键词` 在题面态读成 `关断=END`，交易复原后
读成 `骨骼`；与西北弦的 `企业的` 合为完整中文定义 **`企业的骨骼`**，即
**`CORPORATE STRUCTURE`**。

## 1. 三字块在交叉点交易

- 去掉标点，并把每处四条下划线视作两个汉字空位后，50 行线索恰好拆成 180 个连续三字块。
- 每个横、纵分组的块数多重集与对应白格线长多重集完全一致。
- 将 G1、G2、G3 居中放进同一 13×13 坐标系，恰有 5 个坐标在三盘中同时开放；它们是普通 crossword 没有的深度（`里`）方向。
- 在 42 个平面横纵交叉和 15 个里向交叉处交换相交线索的三字块，57 次全部反向交换后可同时恢复 50 条自然线索。

代表性复原包括：

| 复原线索 | 答案 |
| --- | --- |
| 雷锋是每个小朋友的好□□ | 榜样 |
| 地质学领域中经常被叫作父 | 莱尔 |
| 发生后伤害数字变大 | 易伤 |

三处空白分别补为 `榜样 / 曼丽 / 气性`；它们用于完成线索，不是终答案。

## 2. 拆解答案，以方向内频次填格

提示 2 和风味文本中的“拆解”要求把答案拆成有序可见部件，直到部件数等于格长。例如：

| 答案 | 拆解 | 方向内频次数列 |
| --- | --- | --- |
| 榜样 | 木 / 旁 / 木 / 羊 | 2121 |
| 莱尔 | 艹 / 来 / ⺈ / 小 | 2112 |
| 易伤 | 日 / 勿 / 伤 | 111 |
| 名著 | 夕 / 口 / 艹 / 者 | 1121 |
| 氨气 | 气 / 安 / 气 | 212 |

关键点是频次要分别在题面的三个方向 `横 / 纵 / 里` 内统计，而不是混合统计全部答案：

| 方向 | 频次为 2 的部件 |
| --- | --- |
| 横 | 凵、月、队、木、又、气 |
| 纵 | 艹、小、㇏、又、田 |
| 里 | 气 |

其余部件频次均为 1。把各部件在本方向的频次填进格子后，全部 **57/57** 个交叉点两边数字相等。这个约束也消除了若干语义近似答案：必须使用 `莱尔` 而非泛称地质学家、`易伤` 而非暴击、`名著` 而非世界名著、`氨气` 而非尿骚味。

## 6. `E/N/D→弹筝西北→企业的` 主链与已判错旁路

### 6.1 两个关键词曾被扩写成三维读向

57 次交易复原后，`关键词` 恰好出现两次；这两条完整线索的答案是：

| 复原宿主 | 宿主答案／操作 | 交易前占位块 |
| --- | --- | --- |
| 西十五 / 河海解 / 谜中的 / **关键词** | `反切` | `古代人` |
| 结束本 / 部分的 / **关键词** | `END` | `的概念` |

`反切` 明确规定后续每对字的拼音组合。`END` 不只表示停止：它在中央里向三格中严格拆成 `E / N / D`，三个字母恰可标记三个方向：

| 字母 | 空间含义 | 题面方向 |
| --- | --- | --- |
| E | East | 横 |
| N | North | 纵 |
| D | Depth | 里 |

将 `END` 看成有向循环 `E→N→D→E`，得到统一方向顺序 `横→纵→里→横`。这条循环能生成可复现音流，但 `CORPORATE / WEEKEND / HIGH FLYER / PHILOSOPHY` 的连续判错说明自然成句不足以证明它属于终提取；现只保留为待审计中间读数。

## Candidate audit

- **交易闭合：** 180 个三字块、50 条线索、57 个交叉全部由同一“交叉处交换”规则解释。
- **拆解闭合：** 部件数逐条匹配格长，回应提示 2；方向内频次数盘在 57 个交叉全部一致。
- **三维闭合：** 三盘居中后恰有五个共同白格坐标，承载五条 `里` 线和 15 笔里向交易；这正是提示 3 所说普通 crossword 不存在的维度。
- **数值高频闭合：** 恰有四笔交易两侧数值都为 2；中央 `E/N/D` 提供统一方向循环，取块内第 2 字并反切严格得到 `弹筝西北`。西北里弦三格均为 1，复用同一规则得到 `QI/YE/DE`；另外四条里弦不能形成三个合法音节，因而 `企业的` 不是从同音词表挑出的任意结果。
- **文本高频闭合：** 180 个复原三字块中只有 `关键词` 出现 2 次。选中这同一高频对象的两笔真实交易、以格值 1 索引，复原态严格给 `关古/关的 -> GU/GE`。
- **双态闭合：** 同两笔交易在题面态按方向循环读 `古关/的关 -> GUAN/DUAN=关断`，精确复现宿主答案 `END`；执行交易以后才得到 `GU/GE=骨骼`。这解释了此前闲置的双态，不靠任意同音挑字。
- **联合落字唯一性：** 本地词典只有 6 个 `QI/YE` 双字词和 4 个 `GU/GE` 双字词；24 个 `X的Y` 组合中只有 `企业的骨骼` 自然，离线语言分数领先第二名约 4.35。
- **完整定义：** `企业的` 是所有格前半，`骨骼` 才是其宾语；合起来定义常用英文词组 `CORPORATE STRUCTURE`。已判错的 `CORPORATE` 只是过早停止，不因新候选而恢复为答案。
- **判错解释：** `CONCUBINE` 错在把 `企业的` 接到操作名、再把 `古代人` 当同音类型筛选器；新候选不使用 `qiè/妾`，而复用与前两级完全相同的“最高频对象→真实交易→按格值索引→反切”操作。
- **Meta 使用边界：** 旧 Meta 的语义分配已被 b4=`PEEP`、b10=`INFLOOD` 推翻；当前只记录 `BO / CORPORATESTRUCTURE` 唯一同位字母为第 2 位 `O`，不以此替代本题推导。
- **重复部件延伸反证：** 四个双 2 交点沿相同部件跳到另一实例时，三条落在非交叉网段、一条落在普通值 1 交点，两条 `气` 只在原双 2 点之间循环，不能形成统一路径。
- **末端读出失败：** 在终止词前收集 `伤/势` 虽恰成自然词，但用户已明确判错 **伤势**；这证明自然成词与闭环自指不足以授权该读出。
- **图形文字失败：** `甲青 -> JING1` 与下排 `节气` 都是观察事实，但 `D -> 的` 没有题面授权；用户判错 `惊蛰` 后不得恢复。

- **反证 CFD：** `榜样/曼丽/气性` 的数列确可读成 `C/F/D`，但摩斯操作没有题面授权，且用户已明确判错；不能只换提交“差价合约”。
- **剩余歧义说明：** 中文定义也可泛译为 *company/organizational structure*，题面没有给答案长度；但第一段 `企业的` 直接对应形容词 *corporate*，而 *corporate structure* 是标准搭配，且满足 Meta 的唯一第 2 位 `O`。因此置信度为 `medium` 而非 `high`。三处下划线只用于补全线索。遵照用户要求未联网搜索答案。

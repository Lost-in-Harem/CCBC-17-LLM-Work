# 幻方的交易策略

## Current conclusion

**目前没有可靠的新答案。** 候选 **中山大学** 已被用户明确判错；其依赖的整套填盘也已被题面中的两个精确锚点否定，不能只更换最终提取而保留旧盘。

当前可确认的机制是：把提示语去标点，并将 `____` 视作两个汉字位后，全部 50 条提示都可拆成连续的三字块。若干三字块被“交易”到了别的位置；把它们换回后才能得到真正的提示语。最有力的新证据是两组可同时修复两条提示的直接互换，而不是主题联想。

## Confirmed observations

- 三张平面网格依次为 11×13、13×11、11×13；另有五条“里”提示。
- 50 条提示共含 180 个三字块；按上述空格口径，每条提示的汉字位数都能被 3 整除。可复核表见 `work/trade_chunks.md`。
- 六组横/纵提示在网页中都是无编号 `<ul>`。更关键的是，每一组提示的“三字块个数”多重集都恰好等于该组网格词条长度的多重集：
  - 11×13 盘的横组均为 `3×4, 4×4, 5×1`，纵组均为 `3×2, 4×4`；
  - 13×11 盘的横组为 `3×2, 4×4`，纵组为 `3×4, 4×4, 5×1`。
  这证明每组提示块与该组答案字符之间存在一一对应；但仅凭多重集，尚不能断言列表第 n 条、同块数提示或某个语义修复对应哪一个格槽。
- 第三盘可不改变块内字符地恢复两组强语义片段：
  - `成团口 / 号为扶 / 清灭洋`，即“成团口号为‘扶清灭洋’”，指向 **义和团**；
  - `如童年 / 悲惨世 / 界巴黎 / 圣母院`，恢复为“如《童年》、《悲惨世界》、《巴黎圣母院》”。它既可能提示 **书名号**，也可能提示 **世界名著 / 外国名著**；在完成长度配槽前不能指定为 `G3-D04`。
- 两组互换可直接从原始块位验证，不依赖任何旧答案：
  - `悲惨世`（`G3-A08.3`）与 `清灭洋`（`G3-D04.2`）互换；
  - `圣母院`（`G3-A03.4`）与 `的舌头`（`G3-D04.4`）互换。
  将每组提示块展平后与格槽字符流对齐，它们分别约束 `G3-A08[3] ↔ G3-D04[2]` 与 `G3-A04[3] ↔ G3-D05[1]`。若“高频交易”指相同全局答案字频，这两对位置的字频必须各自相等；具体字符仍待真盘确定。
- `风景区 / 主峰为 / 太平山` 是指向 **明月山** 的三块核心；额外的 `江西省` 暂不占用。类似地，**易中天** 只先占用 `锐评三 / 国还得 / 看老一`，不再为了句子完整强占 `辈的他`。
- 一些残片给出较强但尚未完全复原的答案线索：
  - `攀岩上 / 手的艾 / 尔黛拉` 指向 **终末地**；
  - `初音的 / 黑化版 / 以前有 / 种设定` 指向曾被误认作“黑化初音”的 **黑岩射手**；旧解的 **十六岁** 没有事实或结构支持；
  - 杀戮尖塔的牌组/弃牌成就残片指向 **极简主义（者）**，但题格长度与正式成就名仍须核对；
  - `团子大 / 家族二 / 季藤林 / 干这个` 指向藤林杏后来从事的 **幼儿教师**，但该答案若直接放入当前列表对应的 `G2-D07` 会令交叉处要求一个几乎不存在的三字 `??幼`，进一步支持“列表顺序不等于槽位”的解释；
  - “冀北一最高处”强烈指向 **小五台**，但它尚未被可靠的三层填盘复现。
  - `用呆呆 / 兽尾巴 / 能钓到` 指向 **大舌贝**；`达到指 / 远远地 / 超过所 / 有其他` 指向 **遥遥领先**；`小时候 / 有牛蛙 / 的影子` 指向 **小蝌蚪**。
- 只读核对原题网页后，题面文字与本地保存页一致；链接的腾讯表格是空白只读解题模板，没有公式、编号、填词或勘误。未查看答案记录、未请求提示、未提交答案。

## Working hypotheses

1. **等全局字频交易。** 每个正确提示由现有 180 个三字块重组；已确认的两对互换应落在全局出现次数相同的答案字符位置。下一步只用真答案与格槽交叉检验这条规则，不再使用旧盘制造“相等”。
2. **组级块—字对齐。** 每个横/纵组的块总数与答案字符总数严格相等，且长度多重集相等。提示边界、列表顺序与格槽分配仍需由完整语义和交叉共同决定；不能把“块数相同”单独当作已证明的配槽规则。
3. **“里”是三层校验或提取。** 三盘应在真实填满后再叠读。用旧词链盘穷举三层的旋转、镜像与层序，任何组合都不能读出强锚点“小五台”，所以当前不能继续使用那套叠层结果。
4. **幻方量化 / DeepSeek 是表面主题提示。** 题名与“算法工程师、高频交易”确实指向幻方量化及其 AI 背景，但在出现结构化提取前，不把“深度求索”、人物或学校当作答案猜测。

## Rejected candidate audit

旧方案先挑选一组能闭合二维交叉、又能在五个公共坐标读出 `地震学 / 小五台 / 五面体 / 女超人 / 上中下` 的词，再对横纵答案计字频。该构造产生 `大、地、中、山、学` 五个高频字，随后无约束地重排为“中山大学”。

这条路线现有三层独立反证：

1. 用户明确判定“中山大学”不是答案；
2. “扶清灭洋”语义锚点要求保留 **义和团**，而旧第三盘在相应三字候选链上强填了 `意中人`；三本名著片段也没有被旧盘解释；
3. “高频字”只有多重集而没有受题面约束的顺序，重排步骤本身不可复现。

旧表仅作为失败路线审计保留在 `artifacts/fill-and-extraction.md`，不得再称为已验证填盘。

## Important failed routes

- **中山大学 / 旧纵深适配盘。** 已被用户判错，且旧第三盘不能容纳“扶清灭洋”所要求的义和团语义锚点。不得无新证据恢复。
- **只靠流畅词链补盘。** `研究所—无所不能`、`摩擦力—摩天大楼`、`战技师—胆战心惊` 等链条可以闭合，却不能同时解释真实提示。即使把第二盘纵深字符全部视为未知，穷举第一、三盘的旋转、镜像与层序也无法产生“小五台”或“女超人”，因此至少一套词链盘必须重建。
- **为顺句过度占块。** `江西省 + 风景区 + 主峰为 + 太平山`、`锐评三 + 国还得 + 看老一 + 辈的他` 虽更像完整句子，却分别比强答案“明月山”“易中天”的保守三块核心多占一块；在交叉确认前不得把这些附加块锁死。`初音……种设定` 也应指向黑岩射手，不能再拿官方初音年龄把它解释为“十六岁”。
- **DeepSeek V3 BPE 切词。** `悲惨世 / 清灭洋 / 圣母院 / 的舌头` 不对应该 tokenizer 的稳定 token 边界，详见 `work/token_trade.md`。
- **自动语言模型重排。** 基于词法分数和小型中文 GPT-2 的三次有界实验虽偶尔恢复“悲惨世界 / 巴黎圣母院”等局部搭配，却不能同时恢复两个预设锚点；停止继续调参，结果不作证据。

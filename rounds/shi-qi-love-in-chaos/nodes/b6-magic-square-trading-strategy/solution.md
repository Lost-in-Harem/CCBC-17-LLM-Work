# 幻方的交易策略

## Current status

**状态：`rejected`；当前没有可提交候选。**

用户已明确判定 `易伤` 不正确。三处固定横线严格给出的 `DAMAGE` 以及它对“发生后伤害数字变大→易伤”的唯一定位仍成立，但判题证明链必须继续。此前按答案书写字数走到 `ζ电势 / BREAK` 的路径可能捕捉到了真实结构，也可能只是恰好命中；需要用题面中的“高频”、格内 1/2 数值和交易前后状态为每一步重新提供独立授权，而不能再把闭环结构名当答案。

## 1. 三字块在交叉点交易

- 去掉标点，并把每处四条下划线视作两个汉字空位后，50 行线索恰好拆成 180 个连续三字块。
- 每个横、纵分组的块数多重集与对应白格线长多重集完全一致。
- 将 G1、G2、G3 居中放进同一 13×13 坐标系，恰有 5 个坐标在三盘中同时开放；它们是普通 crossword 没有的深度（`里`）方向。
- 在 42 个平面横纵交叉和 15 个里向交叉处交换相交线索的三字块，57 次全部反向交换后可同时恢复 50 条自然线索。

代表性复原包括：

| 复原线索 | 答案 |
| --- | --- |
| 雷锋是每个小朋友的好□□ | 榜样 |
| 地质学领域中经常被叫作父 | 莱尔 |
| 发生后伤害数字变大 | 易伤 |
| 如《童年》《悲惨世界》《巴黎圣母院》 | 名著 |
| 记忆中厕所里的味道 | 氨气 |

三处空白分别补为 `榜样 / 曼丽 / 气性`；它们用于完成线索，不是终答案。

## 2. 拆解答案，以方向内频次填格

提示 2 和风味文本中的“拆解”要求把答案拆成有序可见部件，直到部件数等于格长。例如：

| 答案 | 拆解 | 方向内频次数列 |
| --- | --- | --- |
| 榜样 | 木 / 旁 / 木 / 羊 | 2121 |
| 莱尔 | 艹 / 来 / ⺈ / 小 | 2112 |
| 易伤 | 日 / 勿 / 伤 | 111 |
| 名著 | 夕 / 口 / 艹 / 者 | 1121 |
| 氨气 | 气 / 安 / 气 | 212 |

关键点是频次要分别在题面的三个方向 `横 / 纵 / 里` 内统计，而不是混合统计全部答案：

| 方向 | 频次为 2 的部件 |
| --- | --- |
| 横 | 凵、月、队、木、又、气 |
| 纵 | 艹、小、㇏、又、田 |
| 里 | 气 |

其余部件频次均为 1。把各部件在本方向的频次填进格子后，全部 **57/57** 个交叉点两边数字相等。这个约束也消除了若干语义近似答案：必须使用 `莱尔` 而非泛称地质学家、`易伤` 而非暴击、`名著` 而非世界名著、`氨气` 而非尿骚味。

**BREAK**

用户已明确判定 `DAMAGE` 不是终答案，所以它应继续充当题内定位词。

## 5. DAMAGE 唯一回指“易伤”

在 50 条复原线索中，只有一条直接出现 DAMAGE 的中文对应词“伤害”：

```text

```

这条线索答案是游戏术语 **易伤**。它并非仅靠语义猜测：在实际纵向网段中，`易伤` 必须拆成 `日 / 勿 / 伤`，三格频次为 `111`；采用这个答案时全部 57 个交叉数值相等，旧答案“暴击”等不满足完整数盘。

因此当前最短、题面授权完整的提取是：

```text
固定横线 → 黛拉／曼丽／记忆 → 反切 → DAMAGE
                                     ↓
                       “发生后伤害数字变大” → 易伤
```

## Appendix A. 被判错的“数网格端→细节”延伸

复原后的 `关键词` 是 180 个三字块中唯一重复的块。它所在两条线索的答案是 **反切** 和 **BREAK**；前者规定了后续读音方式，后者保留为程序式终止词。

对每条复原线索，若答案有 `N` 个书写字符，就把答案末字放在所分配网段的第 `N` 格。`BREAK` 有 5 个字母而里向网段只有 3 格，故作为指令跳过。把三盘居中对齐后，唯一有三个答案末端重合的坐标是 `r10c04`：

## Candidate audit

- **交易闭合：** 180 个三字块、50 条线索、57 个交叉全部由同一“交叉处交换”规则解释。
- **拆解闭合：** 部件数逐条匹配格长，回应提示 2；方向内频次数盘在 57 个交叉全部一致。
- **三维闭合：** 五个共同坐标恰好承载五条 `里` 线，回应提示 3，并使第三处固定横线参与复原。
- **标记闭合：** 题面恰有三处固定下划线；复原后字符对按题面次序唯一给出 `DA/MI/JI = DAMAGE`。
- **指令闭合：** 复原线索答案 `反切` 明确给出读音操作；另一个答案 `BREAK` 位于最后一条源线索并明说“结束本部分”，适合作为终止标记而非提交词。
- **定位闭合：** 50 条复原线索中只有“发生后伤害数字变大”含 DAMAGE 的直接中文对应词；答案是 `易伤`。
- **数盘校验：** `易伤 -> 日 / 勿 / 伤` 给出纵向 `111`，参与 57/57 全交叉相等；语义近似的 `暴击` 不满足完整数盘。
- **最小规则：** 从 `DAMAGE` 到 `易伤` 只需题内唯一文本匹配；继续走到 `ζ电势 / BREAK` 所需的“按答案字数选择三字块”未被标题、风味或提示授权，并已导向判错的 `循环`。
- **剩余风险：** `DAMAGE` 也可泛译为“损伤／破坏”，但题内唯一出现的伤害线索与已由数盘锁定的答案共同显著降低歧义。

# 幻方的交易策略

## Current status

目前没有可辩护的最终答案；高置信的**第一阶段里程碑候选是 `反切`**。

此前把两条含“关键词”的复原行分别解成“反切”和 `BREAK / 中断`，再反切得到 `赚`，但用户已经明确判错。更自然且无需补充步骤的读法，是让重复的 `关键词` 充当两行的连接点：

```text
西十五河海解谜中的 [关键词]
                  [关键词] 是结束本部分的关键词

→ CCBC15《河海解谜》中的关键词，是结束本部分的关键词。
→ 反切
```

“结束本部分”是在说明这个词的用途，即提交它以结束第一阶段，而不是另出一道程序语言线索。全场规则也明确允许没有横幅提示的里程碑答案。

## Observed facts

- 原页面有三张格图、50 条线索。去标点并把每处 `____` 视为两个汉字后，共有 **180 个连续三字块**。
- 每个横、纵分组中，线索的三字块数多重集与同组白格线长多重集一致，所以格长描述的是三字块数，不是线索答案字数。这解释了第二条提示。
- 三图按中心对齐后共有 57 个真实交点；在每个交点交换相交两条线索的三字块，能够同时复原 50 条自然线索。无语义锚点的六次有界重启都收敛到相同的 57/57 交换状态，详见 `work/all_crossings_unanchored.md` 与 `artifacts/all-crossing-reconstruction.md`。
- 对该状态的 180 个块做机械计数，得到 179 种文本；**唯一重复块是 `关键词`，恰好出现两次**。可复现表见 `artifacts/high-frequency-extraction.md`。

## High-frequency extraction

两次 `关键词` 分别落在：

| 位置 | 复原行 | 作用 |
| --- | --- | --- |
| `G1-A07.4` | `西十五 / 河海解 / 谜中的 / 关键词` | 确定关键词的值：**反切** |
| `I05.3` | `结束本 / 部分的 / 关键词` | 说明该关键词用于结束当前阶段 |

第一条中的“西十五”是 `C15 / CCBC15` 的文字化提示，后四字准确指向 CCBC15 的题目《河海解谜》。其[官方存档题面](https://archive.cipherpuzzles.com/ccbc15/problems/5/41.yaml)明确写道：“在第一届河海解谜中，我们决定将反切作为一种标准提取手法”，且整题解析反复使用反切，因此这里的关键词是 **反切**，不是该旧题的最终答案 `GOD SAVE THE QUEEN`。

第二行没有给出一种编程语言，也没有写“程序关键词”；把它独立解释为 `break` 需要额外借用风味文本中的“算法工程师”，而合读法直接利用两行唯一重复的同一块。用户对 `赚` 的判错进一步排除了 `BREAK → 中断 → 反切` 这条延伸。

## Why the design fits

- “拆解问题”提示把怪异线索拆成三字块。
- “交易”指在所有交点交换三字块。
- “高频”不是答案字频或常用词频，而是寻找复原后出现频率最高的三字块；唯一命中 `关键词×2`。
- 两个最高频块所在的整行恰好组成“确定关键词”和“说明关键词用途”两部分。
- 《河海解谜》的官方题面原文直接把 **反切** 称为“标准提取手法”，不是靠旧题答案或模糊联想猜出。
- “结束本部分”准确描述里程碑的阶段边界；提交后的服务器反馈或新题面不在当前存档中。

第一阶段解释使用了标题、风味文本、两条用户提示、三图交点、全部三字块以及旧题引用。当前未使用的信息是里程碑提交后的判题回复，因此不能在离线材料上继续可靠推导最终答案。

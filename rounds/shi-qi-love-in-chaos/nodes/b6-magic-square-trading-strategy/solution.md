# 幻方的交易策略

## Current conclusion

**目前没有达到提交标准的新答案。** 领先解释是 **曼德拉效应**，但仍只算低置信假设：固定横线的局部重建会形成“曼丽／黛拉／记忆”，其中“曼＋（误写成黛的）德拉＋错误记忆”很像在指向曼德拉效应；然而 `丽` 没有被确定规则消去，统一坐标的读序也尚未由题面明确规定。

旧候选 **中山大学** 已被用户明确判错，不能恢复。

## Confirmed observations

- 三张平面网格依次为 11×13、13×11、11×13；居中的五个公共坐标连接出五条三格“里”线。
- 去标点并把每个 `____` 记作两个汉字位后，50 行恰好拆成 180 个连续三字块；每一横/纵分组的块数多重集与相应线长多重集完全相等。
- 三处 `____` 共表示六个汉字位，分别处在：
  - `G1-D03` 第 3 块的第 2、3 字；
  - `G2-D04` 第 2 块的第 2、3 字；
  - `I01` 第 1 块的第 1、2 字。
- 第三盘提供了不依赖旧填盘的强锚点。只在实际交点互换三字块，可以同时复原：
  - `成团口 / 号为扶 / 清灭洋`；
  - `如童年 / 悲惨世 / 界巴黎 / 圣母院`；
  - `发音时 / 说话会 / 用妈妈 / 的舌头`；
  - `学狐狸 / 的技能 / 这件事`。
- 在“同行同块数配槽、交点可换或不换”的几何模型中，共有 50 行、50 槽、180 块、57 个交点。固定上述锚点后，`50000` 步 × `8` 次重启全部回到同一最佳空白行为，执行 46/57 次交换；参数继续变化不再产生新事实，已停止这一搜索族。

## Underline extraction audit

最高分状态中，三处横线所在的固定位置如下：

| 原印刷行 | 配入槽 | 统一坐标 | 交易后进入该横线的块 | 横线上的字 |
| --- | --- | --- | --- | --- |
| `G1-D03` | `G1-D03` | r08c05 | `尔黛拉` | `黛拉` |
| `G2-D04` | `G2-D06` | r03c08 | `丽□□` | `曼丽` |
| `I01` | `Z05` | r10c10 | `记忆中` | `记忆` |

第二处没有发生交换，但完整句严格复原为“形容美丽，**曼丽**之容不悦于目”；“曼丽之容，不悦于目”可由《后汉书》引文独立核对。因此：

- 按网页中横线出现顺序，固定位置读作 `黛拉 / 曼丽 / 记忆`；
- 按 13×13 统一坐标从上到下，读作 `曼丽 / 黛拉 / 记忆`。

后一顺序出现了非常集中的语义信号：`曼丽` 提供“曼”，`黛拉` 是把“德拉”记错一个字的近形，`记忆` 则直接指向错误记忆现象。标准术语 **曼德拉效应** 正是一种群体错误记忆现象。

这还不是闭合提取，原因有二：

1. `曼丽` 中的 `丽` 目前只是承载“曼”的完整词，没有题面规则明确要求丢弃；
2. 三处标记在网页中的顺序与统一坐标顺序不同，题面没有给出显式读序。

若把下划线当作会随三字块移动的内容，而不是固定在格位上的标记，三处可分别补成 `榜样 / 曼丽 / 气性`：

- “雷锋是每个小朋友的好**榜样**”；
- “形容美丽，**曼丽**之容不悦于目”；
- “**气性**不均，则于体不同”。

这组六字既不成常用答案，也不能解释空间位置。用户所说的“横线上的字”确认了提取对象，却没有单独决定横线应随三字块移动还是固定在格位上；目前只是固定标记读法给出了更集中的答案信号。

## Reconstructed local evidence

与三处横线直接相关的最高分修复为：

- `G1-D03 -> G1-D03`：`攀岩上 / 手的艾 / 尔黛拉`；
- `G2-D04 -> G2-D06`：`形容美 / 丽□□ / 之容不 / 悦于目`；
- `I01 -> Z05`：`记忆中 / 厕所里 / 的味道`；
- 空白块本身则分别移动到“雷锋是每个小朋友的好□□”和“□□不均，则于体不同”，或在第二处原位不动。

完整 50 行重建和每次重启的结果见 `work/crossing_trade_results.md`。多数行成为明确的陈述或线索，但仍有“在英国和美国的中间男性向”“这类人电位差带无阻”等没有独立人工核准的行；语言模型排名只能作为搜索工具，不能替代这些核准。

## Important failed routes

- **中山大学 / 旧三层填盘。** 用户已判错；旧盘还把应由“扶清灭洋”复原出的结构强行解释为别的词，且最后把高频字无约束重排。
- **把每个顺句直接当成传统填字答案。** 格网更稳定地解释为三字块交易的几何约束；旧答案表中的交叉闭合不足以证明那些词就是题解。
- **无约束全局语言模型重排。** 三次有界实验不能同时稳定恢复强锚点，已停止。
- **继续调几何模型参数。** 两组有界运行共八个最终重启都不改变空白局部结构；继续调参不会解决“丽”和读序问题。
- **直接串联随块移动的补字。** `榜样曼丽气性` 不成可辨认答案，暂不采用。
- **直接提交固定位置原串。** `黛拉曼丽记忆` 或 `曼丽黛拉记忆` 都不是标准词；它们目前只支持“曼德拉效应”这一解释，不能自身作为答案。

## Next action

不用更多语言模型搜索，改做三处标记的确定性交易审计：把每处横线所在交点的交易前后、统一坐标和读向画成一张小表，寻找题面内生规则来决定网页顺序还是空间顺序，并确认是否有规则从 `曼丽 / 黛拉 / 记忆` 唯一取出 `曼 / 德拉 / 效应`。若仍无法解释多余的 `丽`，则保持 `曼德拉效应` 为低置信假设，不提交，并把缺失规则作为需要人工提示或判题反馈的最小问题。

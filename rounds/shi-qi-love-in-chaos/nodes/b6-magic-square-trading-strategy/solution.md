## 2. 拆解答案，以方向内频次填格

提示 2 和风味文本中的“拆解”要求把答案拆成有序可见部件，直到部件数等于格长。例如：

| 答案 | 拆解 | 方向内频次数列 |
| --- | --- | --- |
| 榜样 | 木 / 旁 / 木 / 羊 | 2121 |
| 莱尔 | 艹 / 来 / ⺈ / 小 | 2112 |
| 易伤 | 日 / 勿 / 伤 | 111 |
| 名著 | 夕 / 口 / 艹 / 者 | 1121 |
| 氨气 | 气 / 安 / 气 | 212 |

关键点是频次要分别在题面的三个方向 `横 / 纵 / 里` 内统计，而不是混合统计全部答案：

| 方向 | 频次为 2 的部件 |
| --- | --- |
| 横 | 凵、月、队、木、又、气 |

## 6. `E/N/D→弹筝西北→企业的` 主链与已判错旁路

### 6.1 两个关键词曾被扩写成三维读向

57 次交易复原后，`关键词` 恰好出现两次；这两条完整线索的答案是：

| 复原宿主 | 宿主答案／操作 | 交易前占位块 |
| --- | --- | --- |
| 西十五 / 河海解 / 谜中的 / **关键词** | `反切` | `古代人` |
| 结束本 / 部分的 / **关键词** | `END` | `的概念` |

`反切` 明确规定后续每对字的拼音组合。`END` 不只表示停止：它在中央里向三格中严格拆成 `E / N / D`，三个字母恰可标记三个方向：

| 字母 | 空间含义 | 题面方向 |
| --- | --- | --- |
| E | East | 横 |
| N | North | 纵 |
| D | Depth | 里 |

将 `END` 看成有向循环 `E→N→D→E`，得到统一方向顺序 `横→纵→里→横`。这条循环能生成可复现音流，但 `CORPORATE / WEEKEND / HIGH FLYER / PHILOSOPHY` 的连续判错说明自然成句不足以证明它属于终提取；现只保留为待审计中间读数。

| --- | --- | --- | --- |
| G1 r05c12 | 横/纵 | `兔干` | TAN |
| G1 r07c02 | 横/纵 | `质锋` | ZHENG |
| G1 r09c10 | 横/里 | `性忆` | XI |
| G3 r09c10 | 横/里 | `百味` | BEI |

### 6.3 已判错：`企业的 + 观念 → PHILOSOPHY`

此前将其描述为古代人的 `观念`：复原线索第一块后面紧接 `观测天` 的首字 `观`，第二个关键词宿主答案 `END` 又可取 `的概念` 末字 `念`。这把两个来自不同上下文的字拼成名词，再把名词补到另一支路，实际包含两次未授权的语义操作：



用户已明确判错 `PHILOSOPHY`。所以这个合并不是把旧候选补完整，而是新的假阳性；也不得改猜 *corporate ethos / ideology / values* 等近义形式。

### 6.4 已判错：`企业的` 直接定位题名企业 `幻方`


题面风味“好的算法工程师……我们做的是高频交易”独立确定这里的 `幻方` 是企业名，而不是只取普通数学义“magic square”。因此本层直接定位企业 `幻方`；该企业的英文名为：


这一步不再复用 `END / 交易 / 反切`，也不取公司名或策略的末字；那些扩写都已分别走向判错的 `WOLF / 量化 / 高频交易`。用户又明确判错 **`HIGH FLYER`**，因此企业名、产品名和公司类型整族关闭。

### 6.5 标题端点得到 `LANG`，但 `WOLF` 已判错

对企业名 `幻方` 与它的 `交易策略` 取 `END`，分别得到 `方 / 略`。题面顺序恰成词 `方略`，本身就是“策略”的同义词，因而自校验了取词范围；再依标题中的“交易”交换两字：

```text
END(幻方) / END(交易策略) = 方 / 略 = 方略
交易：方略 -> 略方
反切：略方 = l + ang = LANG
```


用户已明确回复 **`WOLF` 不是答案**，所以上述 Meta 配位／语义消歧不成立。`狼` 已排除；以下字符串只作为被判错记录：

### 已判错：关键词原位配对得到 CONCEPT

## 8. 被判错的 Fibonacci 延伸

| 递推 | 当前答案 | 位置与交易 | 下一答案 |
| --- | --- | --- | --- |
| `1+1=2` | 易伤（2 字） | 第 2 块 `伤害数`，边 35 | ζ电势 |

- **交易闭合：** 180 个三字块、50 条线索、57 个交叉全部由同一“交叉处交换”规则解释。
- **拆解闭合：** 部件数逐条匹配格长，回应提示 2；方向内频次数盘在 57 个交叉全部一致。

## 3. `STAN LEE` 的否定信息

旧代入为：

```text
X=泵 ← 水落石出
T=上林 ← 曹上＋曹林
洗泵 → 石/stone → STAN
上林刻字 → 李/LEE
```

用户明确判错 `STAN LEE`。直接撤销的是没有题面授权的 stone→Stan；`上林刻字→李`
同时有剩件歧义，且连续多个 `… LEE` 姓名均失败，所以它不再是默认姓氏。不得仅把
STAN 换成 STONE、ROCK 或相邻名称后重投。

## 4. 新打开但尚未闭合的分支

此前的两子词穷举漏掉曹操之子曹乘：

```text
曹上＋曹乘 = 上乘
```

`上乘刻字` 可按完整四字谜面得到姓氏 `季`：

```text
乘 − 北 = 禾
字 − 宀 = 子
禾在子上 = 季
```

同义成语侧，`不言而喻` 去掉“言”旁得到常见姓氏字 `俞`，是目前最规整的完整谜面：

```text
不言而喻 → 俞
```

这给出一个待验末态 `洗｜俞｜季`。它还不是候选答案：目前只能联想到
`XI-YU-JI` 一类读音串，无法严格说明七月为何把 `洗、俞` 替换成一个西文名称，
也不能证明该串是最终英文答案。

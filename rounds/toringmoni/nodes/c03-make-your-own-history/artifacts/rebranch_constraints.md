## 3. 三个锁链字谜

### `一目了然 → 子`

删除 `罪与罚` 后，第三项不再被锁到 `一清二楚→三明`。改取直接同义成语
`一目了然`；把其中的 `一` 加到 `了` 中得到常见字 `子`。它不含天气字或七曜，
能通过六月筛选。

### `上 → 右 → 右宅子 → 孔`

曹上、曹林组成 `上林` 后，猫王步骤多出第一遍不存在的方位 `上`。顺时针旋转
90° 得 `右`。`宅` 的最右笔形为 `乚`，与条目中的 `子` 合成：

```text
子 + 乚 = 孔
```

这正落实提示 4 的“之前的某些历史现在可以走上新的分支”。字形审计见
`right_branch_components.png`。

### `上林刻孔 → 李 → LEE → 李`

四字谜面按四个角色读取：`上` 指定上下结构，`林` 提供 `木`，`刻` 表示刻取部件，
`孔` 提供 `子`；木在子上得到姓氏 `李`。因为外部尚有 `洗、子` 两项，七月条件
触发，把刚合成的四字条目替换为西文名称 **LEE**。八月再按“合适姓氏”换回 `李`。

最终组合不是把三个字直接音译，而是继续按风味指定的谜语方法读取：

```text
洗｜子｜李 ＝ 从“李”中洗去“子” ＝ 木 ＝ WOOD
```

## 4. 判错与消歧

- 用户已明确判错 `WHITE HORSE`。旧链 `一清二白→泊→WHITE`、
  `上乘刻字→MARK/马克→马` 不能成组复用，也不尝试其拼写近邻。
- 七月采用“外部条目数是触发条件，替换刚合成的四字条目”的句法；这样
  `上林刻孔` 才先变成 `LEE`，八月再执行 `LEE→李`。这也比把外部 `洗、子`
  自己替换掉更符合“将最后三个条目合并……则合并后替换”的省略主语。
- `上乘刻孔→季` 也能勉强按部件拼出姓氏，但 `季` 没有像 `李→LEE` 一样无歧义的
  西文名称，并且终串不能反向完整消费 `子`；因此由最终 `洗子李→木` 消歧到 `上林`。
- 记录在本题旧日志中的 Meta 反推尚不能与 `WOOD` 机械对齐，属于当前重要未用信息；
  它降低置信度，但不覆盖这条由题面八句话逐格复现的主链。

全链按用户要求离线推理，没有搜索比赛答案。

## 确立的机制（M80）

1. 每段本是一句正常英语，其中若干个**有中文雅译的音译外来词**被动了手脚：
   **把该外来词的一段连续字母替换成一个普通英文单词**，句子于是读起来"差一点就通"。
2. 标记 `方框(a/b)`：**`b` = 该外来词英文原词的字母数**，**`a` = 取第 a 个字母**，
   **方框个数 = 该词中文雅译的汉字数**。
3. 提示 5：一段的若干标记取出的字母拼成一个英文词（该段答案），
   这个词正是该句**句意**所指的那个音译词里**某一个汉字的意思**。

### 本次唯一自行确认的一段：第 5 段 = ASIA

加上"载体文本区间两两不相交"这个硬约束（`artifacts/disjoint.py`）后，第 5 段
得到唯一自洽解，四项（字母数 / 汉字数 / 取字位置 / 区间不重叠）全部吻合：

| 标记 | 外来词 | 雅译 | 取字 |
| --- | --- | --- | --- |
| ■■■(3/6) | FRANCE | 法兰西(3字) | [3] = **A** |
| ■■(4/5) | TOAST | 吐司(2字) | [4] = **S** |
| □■■(5/8) | HYACINTH | 风信子(3字) | [5] = **I** |
| ■■(2/5) | PARTY | 派对(2字) | [2] = **A** |

→ **ASIA = 亚**；句意"他若吃的是花而不是那颗果子就可能被认定无罪"指伊甸园的**亚当**。

## 知道答案后的回看

- **曾母暗沙** 正是本题主题的样板：`曾母` 是 James 的音译（曾/母 都是有字义的汉字），
  `暗沙` 是 shoal 的意译（暗 = hidden、沙 = sand）。
- **第 6 段几乎肯定是 SAND（沙）**：句意"一个小点……要是它正好在**荒无人烟的正中间**呢"
  说的就是暗沙/沙洲；而本 Node 独立算出的约束是"第 6 段答案第 2 个字母 = A"
  （RAMEN 拉面 [2]=A），SAND 正好满足。当时没有往"沙"上想。
- 姊妹页的 **"引领远航者的方向"** 与 **`4.4.1.3`** 应是指向最终地点的定位线索
  （曾母暗沙约在 N3°58′ / E112°17′），本 Node 始终没解出它们与六段词的接法。

## 没能闭合的地方（失败原因）

1. **六段词只拿到一段。** 第 1、2、3、4、6 段在不相交约束下都拼不出像"汉字义"的词，
   根本原因是 `artifacts/yayi.txt`（外来词 → 中文雅译，最终 739 条）覆盖不足；
   对照实验（`artifacts/jscan.py`）证明**汉字数约束是唯一有效的收敛器**，
   去掉它每个标记就有 30–280 个候选。
2. **`(3/4 4)` 里第二个 4 的含义始终没定**（两个标记并排？两词地名 4+4？取第 3 和第 4 位？），
   第 1 段一直卡在这里。
3. **三个光秃秃的 `(5)` 标记**（第 2 段两个、第 6 段一个）没有分子；取末位/取首位/
   把 5 当序号三种读法都试过，第 2、6 段仍拼不出词。
4. **最后一层（六段词 → JAMES SHOAL）完全没有触及。**

## 走错的大弯路（保留作反面记录）

前期把机制误判为"句中藏城市名的变位词"，围绕
"连续窗口 = 分母 + 方框数、方框表示多余字母是否也出现在城市名里、`(a/b)` 取城市第 a 个字母"
建了 M28–M33 一系列模型，产出过 `ceranflower = FLORENCE + RAW → E`、
`hailus and = LUANDA + HIS`、`ailusandamen = ANDALUSIA + MEN` 等"锚点"。
这些**全部作废**——只是长度与多重集的巧合。教训：一个锚点同时满足"多重集 + 方框图样"
两项时看起来很硬，但只要没有第三项独立约束（这里应是"抽掉载体后原句仍然通顺"），
整条链都可能是假的。

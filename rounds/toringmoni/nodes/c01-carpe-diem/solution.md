# 把握今朝

## 本轮最重要的结论：题面是每分钟重生成的

之前的记录假设 `input/1.png`–`4.png` 是固定题面。本轮从 SingleFile 存档里
解出了原始 DOM，四条互相独立的证据推翻了这个假设：

1. 谜面正文只有一句话：**「我这一生只会为你停留一次，只有这一分钟。」**
   （`input/把握今朝.html` → `index.html`，`puzzle-flavor` 区块；题目正文本身只有
   一条带三个 📁 的虚线分隔 SVG，没有别的内容。）
2. 秒克账号「少年维持着烦恼」的简介写着
   **「把容易被忽略的瞬间留下来。有些事情只有反复观看，才会看清楚。」**
3. 四张图所在帖子的配文就是 **「一些随机图片」**。
4. 简介里的时钟是实时的：`input/1.html` 抓于 **23:47**，`2/3/4.html` 抓于
   **23:48**（页面内 `现在是2026年8月17日23:4X` 逐条核对）。把 13:03 与 23:47
   两次抓取并排看，四张图的内容全部不同。

因此本题不是「解出一组固定字符再提交」，而是
**在同一分钟内读完四张图、算出四个结果、立刻提交**。
这也直接解释了 `Submission history` 里三次被拒：`黄飞虎牛`、`五色神牛`、
`黄飞虎` 都是隔了很久之后补交的过期串，而且 `黄飞虎` 里的「飞」来自 23:48 的
第二张图、「黄」来自 23:47 的第一张图——连这两个字都不属于同一分钟。

顺带修正：`input/1.png`–`4.png` 只是那两分钟的截图，不是题面本体；
`input/1.html`–`4.html` 才是可精确复原的 DOM。

## 第二张图：机制已解出（刘禹锡《乌衣巷》末联）

DOM 结构（`input/2.html`）：页首 `🟥🟦🟨 = S`，一个 7 列 2 行的 `box-grid`，
页脚 `作者 ∈ S252`。燕子图片上叠着红色 `S315`。

`S` = **百家姓序号**，已用语料逐位核对（`work/data/baijiaxing.txt`，来自
chinese-poetry 的 `蒙学/baijiaxing.json`）：

| 标记 | 字 | 标记 | 字 |
| --- | --- | --- | --- |
| S31 | 陶 | S96 | 黄 |
| S82 | 于 | S131 | 蓝 |
| S85 | 皮 | S252 | **刘** |
| S87 | 齐 | S315 | **燕** |
| S80 | 常 | S400 | 红 |

页首那句因此可以读通：**红、蓝、黄三个色块本身都是百家姓里的姓**，用来告诉你
`S` 就是「姓」。燕子图配 `S315` 是同一种示范。

把线索合起来：**七言两句（7×2）+ 燕 + 满格的杂姓（百姓）+ 作者姓刘**
= 刘禹锡《乌衣巷》末联

> 旧时王谢堂前燕，飞入寻常百姓家。

「王」「谢」是姓、「燕」是燕子、「百姓」就是百家姓——图上散落的随机姓氏和燕子
正是这两句的图解。答案 = **问号格在这两句里对应的那个字**：

- 23:48 抓取问号在第 2 行第 1 格 → **飞**；
- 13:03 抓取问号在第 2 行第 7 格 → **家**。

两次问号都落在第 2 行（「飞入寻常百姓家」）。

**已验证的否定结论**：格子里的 `S` 下标不是该位置的诗句字。我在
全唐诗＋全宋诗共 311,855 首里检索过：没有任何一位刘姓作者的七言联满足
「上句第 2 字 = 齐 且 下句第 4 字 = 陶」（放宽到任意作者也为零），
13:03 的「皮 / 于」同样为零。所以那些 `S` 数字和燕子图是随机装饰（正是
「寻常百姓」和「堂前燕」的意象），不是逐格填字。

## 第一张图：问号行的图案 → 「黄X」，对照表未建全

DOM（`input/1.html`）：三行 `riddle1-row`，每行一个 `riddle1-square`
（颜色恒为 `--c:#13b6c4`，青）加 `=` 加一张图片，第三行图片位置是红色问号。

已知对照：

| 方块 class | 结果 |
| --- | --- |
| `sq--solid`（全青） | 黄鳝（图片 class `riddle1-image--huangshan`，砂锅黄鳝，已看原图确认） |
| `sq--lr-left`（左半青） | 黄鹂（`riddle1-image--huangli`，黑枕黄鹂） |
| `check-tl`（2×2 交错） | 黄酒（13:03 记录） |
| `check-tr`（互补的 2×2） | 黄雀（13:03 记录） |

四个已知结果都是「黄X」。两次抓取里问号行都是 `sq--solid`，若这一点稳定，
第一张图的结果恒为 **黄鳝**；但两次样本不足以排除巧合，而且 CSS 只保留了当次
用到的两条 `sq--` 规则（SingleFile 会裁掉未使用的样式），完整图案表还没拿到。

## 第三张图：普通迷宫模型已被证伪

`artifacts/maze_graph_analysis.py` 直接从 `input/3.html` 里的内嵌 SVG 读出
36 条 `maze-wall`、16 个 `maze-axis` 圆点和 5 只动物，无需 OCR。23:48 的盘面：

```text
+   +---+---+---+---+
| 羊     |           |
+---+---+   +---+---+
|     马 |   |       |
+   +---+   +---+   +
|   |     鱼         |
+   +   +   +---+---+
|   |       |       |
+---+   +   +---+---+
|     鸟 |         虎 |
+---+---+---+---+   +
```

按「没画线就能通过」的普通判定，25 格被切成 **4 个连通块**，入口块只有
`{(1,1),(1,2)}`，根本到不了出口，与动物无关。内部开边 22 条（完美迷宫需要 24
条且只有 1 个连通块），所以这不是普通迷宫，而是另一种规则。

稳定特征：羊恒在入口格 (1,1)，虎恒在出口格 (5,5)，鱼两次都在 (3,3)；马和鸟会动；
16 个内部格点全部画有白色圆点（不是选择性的，所以「圆点=传送门」的旧假设失去
依据）。题注恒为「走到终点，注意避开所有动物！」。

已试过并否定的模型：普通缺边移动（不连通）、圆点处四向斜穿（出现 6 条并列最短
路，答案不唯一）、只允许斜穿（第一步就被马挡死）、把 PNG 当像素障碍。

## 第四张图：只有一行能复现

DOM（`input/4.html`）：`rebus-grid`，三行「汉字 + 汉字 ↔ 汉字」，第三行答案是问号。

| 时刻 | 第 1 行 | 第 2 行 | 第 3 行 |
| --- | --- | --- | --- |
| 13:03 | 牛 − 人 ↔ 精 | 乐 + 奴 ↔ 西 | 呢 − 米 ↔ ? |
| 23:48 | 狗 + 儿 ↔ 忠 | 喜 + 娇 ↔ 西 | 吽 + 油 ↔ ? |

唯一能复现的一行是 23:48 的第 2 行：娇取「女」，与「喜」组成 **嬉**(xī)，同音得
**西**。但这条规则不通用，已用 IDS 字形库（cjkvi-ids）+ Unihan 读音穷举验证：

- 「狗 + 儿」的部件只能拼出 兄(xiōng)、𠮜、𠁤，没有任何读 zhōng 的字，配不上 忠；
- 「乐 + 奴」只能拼出 ⿰女樂 = 㜰(yuè)，没有读 xī 的字，配不上 西；
- 「牛 + 人」只有 件(jiàn)，配不上 精。

也逐条否定过：笔画数加减、部首序号加减、四角号码、仓颉码、Unicode/GB2312 码值、
声母韵母反切、声调加减、汉字结构类型循环。两次抓取第 2 行答案都是「西」，
可能是巧合，也可能第 2 行是固定示范位——样本不足以判断。

## Important failed routes and caveats

- **前提错误**：把四张截图当成不变的题面。它们每分钟重生成，四张图必须在同一
  分钟内读取；23:47 的第一张图和 23:48 的其余三张已经不属于同一次生成。
- `黄飞虎牛`、`五色神牛`、`黄飞虎`：均被用户明确拒绝。三者都是过期串，且混用了
  两个不同分钟的图；在拿到新的同分钟样本之前不要重提。
- 第二张图：`S` 下标不是格内诗句字（311,855 首唐宋诗全库检索为零）。
- 第三张图：普通迷宫、四向斜穿、纯斜穿、像素障碍四种模型均已证伪。
- 第四张图：「取双方部件组字再取同音字」只解释 6 行里的 1 行，不是通用规则。
- 不把 `4.3.1.3` 当本题算式；按用户说明它属于 Meta（同类标记在其他 App 里也有：
  `7.3.4.5`、`16.1.9.4`、`17.12.7.3`、`6.2.6.1`、`18.17.7.14`）。
- 谜面正文那条分隔线 SVG（30 个位置，📁 在第 2、8、18 位）目前只当装饰，没有
  可验证的用途。

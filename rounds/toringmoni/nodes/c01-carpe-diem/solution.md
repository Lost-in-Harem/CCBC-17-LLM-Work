用户已经明确反馈：`黄飞虎牛` 和 `五色神牛` 都不是答案。这两条路线不能再当作

分别仍有“取首字”“终点动物”“偏旁同音”的解释假设。

此前最值得验证的中间答案 **黄飞虎** 已被用户单独提交并明确拒绝；因此不能再把
前三图的首字/终点动物拼接当作中间答案。

四图的可复现观察与假设见 `artifacts/fixed_photo_solution.tsv`。

## Photo 1：黄鳝，或其首字“黄”

第二、三行左侧是完全相同的青色实心方块，所以问号必须与第二行右侧使用同一
图片。前端固定资源表把该图标作 `huangshan`，图中是**黄鳝**。因此完整表层结果
是“黄鳝”。在总链里只取首字“黄”能够与第二、三图组成“黄飞虎”，但题面没有
直接写出“取首字”，所以这一步仍是提取假设，不能单独视为已证实。

## Photo 2：飞（已较强确认）

图头的三个色块给出 `S`，而 `S` 的下标是《百家姓》中的位置。固定图中可核对：

| 标记 | 百家姓字 |
| --- | --- |
| `S31` | 陶 |
| `S87` | 齐 |
| `S252` | 刘 |
| `S315` | 燕 |

大量燕子、两排七格和“作者 ∈ S252”（作者姓刘）共同指向刘禹锡《乌衣巷》的末
联：

> 旧时王谢堂前燕，飞入寻常百姓家。

当前问号在第二排第一格，故填 **飞**。诗句可用
[《乌衣巷》原文](https://meirishici.com/quote/874/source)复核。格内其他百家姓是
“百姓之家”的干扰/装饰，不逐格替换诗句。

## Photo 3：迷宫规则和提取仍未定

可直接观察到：这是 5×5 格，入口在左上格上方，出口在右下格下方；羊固定在
入口格、虎固定在出口格，内部还有马、鱼、鸟。题注是“走到终点，注意避开所有
动物！”。

把黑线当普通格墙、只允许缺边移动时，入口区域只有两个可达格，无法到出口；把
固定 PNG 当作像素障碍做 4 邻接 BFS 也无法到出口。这些是已复现的失败模型，不应
据此直接把出口旁的虎当成答案。

一个与图上所有圆点相符的有限模型是：普通缺边移动之外，在圆点处允许两个相邻
象限通过，前提是两个象限各有至少一条未画出的侧边（`cross-open-one`）。在当前
截图中，避开马、鱼、鸟后得到唯一最短格路线（行列从 1 起）：

```text
(1,1) → (2,1) → (3,2) → (4,3) → (5,4) → (5,5)
```

这说明圆点很可能是跨角通道，但“圆点的准确通行规则”并未在题面文字中明示，
且路线尚未给出可靠的字母/汉字编码。因此 Photo 3 目前只能保留“出口动物为虎”
这一中间观察，不能宣称虎就是独立答案。

复现实验脚本：`work/visual/maze_portal_rules.py`；当前路线结果见
`work/visual/maze-cross-test.json`。

## Photo 4：当前行可解释为牛，但首行有矛盾

第二行是最清楚的示范：从“娇”取女旁，与“喜”组合成“嬉”，读音同“西”。当前
第三行同理：

1. “吽”提供部件 **牛**；
2. “油”提供三点水 **氵**；
3. 组合成生僻字 **汼**（`⿰氵牛`）；
4. “汼”读 `niú`，所以右侧同音字可填 **牛**。

不过第一行 `狗 + 儿 ↔ 忠` 无法按同一严格部件替换规则复现；例如形近的
`狆 = 犭+中` 读 `zhòng`，但题面给的是“儿”而非“中”。因此把第三行读成牛
是有依据的局部结果，却不能据四行声称机制已经完全闭合。

## 已排除的拼接假设

先前按当前最自然的首字/终点读法，前三图被写成：

```text
黄（黄鳝） + 飞（《乌衣巷》） + 虎（出口动物） = 黄飞虎
```

这一路线现在已被三次反馈排除：带牛的 `黄飞虎牛`、神话联想 `五色神牛`，以及
单独的 `黄飞虎` 均不是答案。因此“黄鳝取黄”“出口取虎”至少有一处不是正确提取，
也不能继续把第四图的牛接到这个名字上。

# 五雷灌顶：五关提取记录

坐标从 0 开始。棋盘宽度恒为 75；顶部五个独立单元的目标格位于
`(row, column) = (3, 5), (3, 11), (3, 17), (3, 23), (3, 29)`。
目标格含雷记 `1`，否则记 `0`，从左到右作为五位二进制，并按
`1=A, ..., 26=Z` 转字母。

## 结构模型

- 顶部之后是若干个 21 行模块；棋盘高度均为 `5 + 21n`。
- 五根总线的中心列为 `5, 11, 17, 23, 29`。
- 每个模块有三个接线位。将总线局部切成 6×6 小块后，前三关完整雷图中：
  总线值 0 和 1 各只有 6 种局部雷形。
- 右侧三个接线位分别只有 4、4、7 种局部雷形。
- 因而不能复制整个 21×75 模块，但可以平移复用这些最小固定元件。

## 提取

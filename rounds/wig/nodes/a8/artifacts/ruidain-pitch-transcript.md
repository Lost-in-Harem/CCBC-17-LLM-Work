## 八页路演逐页转录

### 01 / 08

- 驾驶本文化传媒有限公司
- `让角色走出直播间，也走进游戏里。`
- 虚拟主播 × 游戏的闭环 IP 生态
- 演讲者：黄紫捷

### 02 / 08 — 我们的业务

- `两个部门，一个 IP 闭环。`
- 虚拟主播部门 ↔ 角色内容 / 用户 ↔ 游戏部门
- 公司分为虚拟主播和游戏两个部门，构建闭环 IP 生态。

### 03 / 08 — 游戏部门 / TEAM

- `小团队，明确到每一把椅子。`
- 3 名美术：原画、模型、动画与特效
- 3 名程序：客户端与工具链
- 2 名策划：玩法、系统、关卡与版本执行
- 1 名运营负责人：由黄紫捷本人负责

### 04 / 08 — 虚拟主播部门 / CAST

- `三位主播，两名运营。`
- 3 个主播：持续输出直播与角色内容，签署长期艺人合作合同，不计入正式员工。
- 2 名运营：负责日常支持与内容协作。
- 早期不投入额外买量运营成本；等待游戏正式上线盈利后再增加虚拟主播部门运营投入。

### 05 / 08 — 角色视觉 / CHARACTER

- `模型，交给懂角色的人。`
- 虚拟主播模型由业内知名画师 **范皋** 负责，以统一角色语言连接直播内容与游戏资产。

### 06 / 08 — 本轮目标 / RUNWAY

- 周期：12 个月
- 目标：完成团队搭建、主播启动与游戏原型验证。
- 办公成本：¥0
- 办公地点：蕊滇孵化器；免费共享创业办公场所，行政法务费用由孵化器支持。

### 07 / 08 — 12 MONTH ROADMAP

- `从角色亮相，到第一个可玩版本。`
- Q1：核心团队到位；角色设定定稿
- Q2：主播首播；游戏原型完成
- Q3：内容稳定更新；社区测试
- Q4：闭环联动验证；下一轮准备

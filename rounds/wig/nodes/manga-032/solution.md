## Observed layout

## Reproducible extraction — 纸牌

两问号水平相邻，既可分别作为一个字，又可整体作为一个双字词。不能额外假定每条箭头都只构成双字词。

| 方向 | 填入后 | 图片含义 |
| --- | --- | --- |
| 手 → 左字 | 手纸 | 手 = 手 |
| 手 → 右字 | 手牌 | 同上，不更换为掌 |
| 左字 → 面条 | 纸面 | 面条给出面 |
| 右字 → 面条 | 牌面 | 同上 |
| 蜘蛛 → 两字整体 | 蜘蛛纸牌 | 直接使用蜘蛛的完整名称 |
| 两字整体 → 房屋 | 纸牌屋 | 房屋给出屋，作品名兼常用名词 |

从左到右填 **纸、牌**，得到 **纸牌**。此前漏掉了两个问号作为整体的读法，才会误把蜘蛛换成“网”并在两个孤立位置盲配词。六条箭头及输出顺序均已解释，没有逆读。稳定节点位置和完整词路径见 `artifacts/word-paths.json`。

## Important failed routes — 球门

箭头两端组合成常用双字词。设左问号为 X，右问号为 Y：

| 图中连接 | 成词 | 结论 |
| --- | --- | --- |
| 手 → X | 手球 | X = 球 |
| 蜘蛛 → X | 网球 | 蜘蛛提供“网” |
| X → 面条 | 球面 | 面条提供“面” |
| 手 → Y | 掌门 | 手提供“掌” |
| Y → 房屋 | 门房 | 房屋提供“房” |
| Y → 面条 | 门面 | 面条提供“面” |

上述复合词虽然分别存在，但更换了“手”的映射，而且蜘蛛并非蜘蛛网；网站已拒绝球门和门球，因此并不是可靠闭环。
